CASIO fx-CG50

Menu: 2: Statistics

1 Introduzir os Dados (3 Formas Possíveis)

  1. Prime MENU → 2: Statistics.
  2. Caso A — Lista Simples (pág. 47): Escreve todos os valores na List 1 (mesmo que repetidos).
  3. Caso B — Tabela de Frequências (pág. 48): Escreve os valores na List 1 e as frequências absolutas (ni) na List 2.
  4. Caso C — Dados em Classes (pág. 49): Calcula a marca da classe (ponto médio do intervalo), coloca na List 1 e as frequências na List 2.

2 Configurar (SET) e Calcular (1-VAR)

  1. Prime CALC (F2) → SET (F6).
  2. Configura a frequência conforme como inseriste os dados:
    • 1Var XList: List1
    • 1Var Freq: 1 (se usaste só List 1) OU List2 (se tens frequências na List 2).
  3. Prime EXIT → 1-VAR (F1).
  4. Usa ↑ ↓ para ler: x̄, sx, minX, Q1, Med, Q3, maxX e Mod.

3 Diagrama de Extremos e Quartis (MedBox)

  1. No ecrã das listas, prime GRAPH (F1) → SET (F6).
  2. Muda Graph Type para MedBox, XList: List1, Frequency: 1 (ou List2) e Outliers: Off.
  3. Prime EXIT → GRAPH1 (F1) → SHIFT+F1 (Trace) para percorrer os 5 pontos.
Texas Instruments

TI-84 Plus / TI-84 Plus CE

Tecla: STAT

1 Introduzir Dados (L1 e L2)

  1. Prime STAT → 1: Edit...
  2. Dados simples: Escreve tudo em L1.
  3. Tabela ou Classes: Escreve valores (ou marcas de classe) em L1 e frequências em L2.

2 Calcular Medidas e Boxplot

  1. Medidas: Prime STAT → seta → (CALC) → 1: 1-Var Stats. Define List: L1 e FreqList: vazio (ou L2 via 2nd+2) → Calculate.
  2. Boxplot: Prime 2nd+Y= (STAT PLOT) → 1: Plot1 → On → escolhe o 5.º ícone (sem outliers) → Xlist: L1, Freq: 1 (ou L2) → ZOOM + 9.
Texas Instruments

TI-Nspire CX / CX II-T

App: Listas e Folha de Cálculo

1 Folha de Cálculo, Estatísticas e Boxplot

  1. Abre Listas e Folha de Cálculo. Dá nome à coluna A (dados) e preenche valores (ou marcas de classe). Se houver frequências, dá nome à coluna B (freq).
  2. Calcular Medidas: Prime MENU → 4: Estatística → 1: Cálculos Estatísticos → 1: Estatística de uma variável. Escolhe Lista X1: dados e Frequências: 1 (ou freq).
  3. Boxplot: Prime CTRL+I → Dados e Estatística → clica em baixo para escolher dados → MENU → 1: Tipo de Gráfico → 2: Diagrama de Extremos e Quartis.

1. Como Calcular a Média (x̄)

Símbolo no ecrã: x̄ (ou Média μ na NumWorks)

Consoante a forma como o exercício te dá os dados, existem 3 maneiras de os introduzir na calculadora (exemplos baseados nas páginas 47, 48 e 49 do manual):

Caso 1 • Pág. 47

Dados Soltos à Mão (Lista Simples)

Quando tens uma lista pequena de números (mesmo que haja valores repetidos, ex.: 24, 25, 29, 25):

  1. Coloca todos os números na 1.ª coluna (List 1 / L1 / V1), um por linha, incluindo os repetidos.
  2. Define a Frequência como 1 (ou deixa FreqList em branco na TI-84).
  3. Executa 1-VAR e lê o valor de x̄.
Caso 2 • Pág. 48

Tabela (Dado + Frequência)

Quando os dados estão agrupados numa tabela de frequências (ex.: N.º de golos e n.º de jogos):

  1. Na 1.ª coluna (List 1 / L1 / V1), escreve os valores da variável (xi).
  2. Na 2.ª coluna (List 2 / L2 / N1), escreve as respetivas frequências absolutas (ni).
  3. Em SET / FreqList, muda a frequência de 1 para List 2 / L2!
  4. Executa 1-VAR e lê x̄.
Caso 3 • Pág. 49

Classes (Usar a Marca da Classe)

A calculadora não aceita intervalos como [10, 30[. Tens de calcular primeiro o ponto médio:

Marca da Classe = (Início + Fim) ÷ 2
Ex.: [10, 30[ → (10 + 30) ÷ 2 = 20
  1. Escreve as Marcas das Classes na List 1 / L1 / V1.
  2. Escreve as Frequências Absolutas na List 2 / L2 / N1.
  3. Define Freq = List 2 / L2 e executa 1-VAR para obter a média aproximada x̄.
⚠️ Erro mais comum nos testes: Fazer um exercício do Caso 2 ou 3 (com tabela na List 2) e esquecer de mudar o Freq de 1 para List 2 (ou vice-versa, fazer uma lista simples e deixar lá esquecida uma List 2 antiga!). Confirma sempre o n (total de dados) no ecrã de resultados!

2. Como Obter a Moda (Mₒ)

Valor ou categoria que ocorre mais vezes
Calculadora Como obter a Moda
CASIO fx-CG50 No menu 1-VAR, desce com a seta ↓ até ao fundo da lista: aparece Mod = ... (e Mod:n indica se há mais do que uma moda).
TI-84 Plus C Não calcula diretamente. Ordena a lista (STAT → 2: SortA(L1)) ou vê qual o valor com maior frequência na coluna L2.
TI-Nspire CX Não aparece no 1-VAR. Podes ordenar a coluna ou escrever numa página de Calculadora: mode(dados).
NumWorks Aparece diretamente no separador Estatísticas com o nome Moda.
💡 Nota sobre Classes: Se os dados estiverem agrupados em intervalos (histograma), não se diz "Moda", diz-se Classe Modal (o intervalo com maior frequência absoluta).
Medida de Localização • Págs. 52–53

3. Como Obter a Mediana (Mₑ)

Divide os dados ordenados ao meio (50% / 50%)
  1. Introduz os dados na 1.ª coluna (e as frequências na 2.ª coluna, se existirem).
  2. Executa o cálculo estatístico de 1 variável:
    • CASIO fx-CG50: CALC → 1-VAR → desce com ↓ até ler Med.
    • TI-84 Plus C: STAT → CALC → 1-Var Stats → desce com ↓ até ler Med.
    • TI-Nspire CX: MENU → 4: Estatística → 1: Cálculos Estatísticos → 1-Var → lê MedianX.
    • NumWorks: Separador Estatísticas → lê Mediana.
📌 Quando preferir a Mediana à Média? Sempre que existirem outliers (valores muito discrepantes/extremos, como no exemplo do teatro da pág. 46 do manual), pois a mediana não é afetada por valores extremos!

4. Quartis (Q₁, Q₂, Q₃) e Percentis (Pₖ)

Dividem os dados em blocos de 25%

Leitura Direta dos Quartis no Ecrã (1-VAR)

Em todas as calculadoras, logo a seguir ao cálculo de 1 variável (usando as setas ↓), aparecem os três quartis por ordem:

Medida Sigla no Ecrã Percentil Equivalente Significado Prático
1.º Quartil Q1 P₂₅ Pelo menos 25% dos dados são ≤ Q₁.
2.º Quartil (Mediana) Med / MedianX P₅₀ Pelo menos 50% dos dados são ≤ Mediana.
3.º Quartil Q3 P₇₅ Pelo menos 75% dos dados são ≤ Q₃.
🔍 E os outros Percentis (ex.: P₁₀, P₈₅)? As calculadoras gráficas não calculam percentis arbitrários diretamente no menu 1-VAR. Para os encontrar, olha para a coluna da Frequência Relativa Acumulada (Fᵢ%) da tabela e vê qual o primeiro valor que iguala ou ultrapassa a percentagem pedida.

5. Diagrama de Extremos e Quartis (Boxplot)

"Caixa de Bigodes" (5 pontos)

Atalhos Rápidos por Máquina

  • CASIO fx-CG50: GRAPH → SET → Graph Type: MedBox, Outliers: Off → EXIT → GRAPH1 → SHIFT+F1 (Trace).
  • TI-84 Plus C: 2nd+Y= → Plot1: On → 5.º ícone (sem outliers) → ZOOM + 9 → TRACE.
  • TI-Nspire CX: CTRL+I → Dados e Estatística → escolher variável → MENU → Tipo de Gráfico → Diagrama de Extremos e Quartis.
  • NumWorks: Separador Gráfico → Diagrama de extremos e quartis.

6. Medidas de Dispersão (Variabilidade)

Medem o quanto os dados estão espalhados
Medida de Dispersão Como obter na Calculadora Nota Prática
Desvio-Padrão Amostral (s) Lê diretamente no menu 1-VAR:
• CASIO / Nspire: sx
• TI-84: Sx
• NumWorks: s		 Usa sempre este (ignora o σx, a menos que o exercício diga que é a população toda).
Variância (s²) Eleva o desvio-padrão ao quadrado: (sx)²
(A NumWorks mostra logo s²).		 Quanto maior for, mais afastados da média estão os dados.
Amplitude Total Calcula à mão com os extremos do ecrã:
maxX − minX		 Diferença entre o valor maior e o menor.
Amplitude Interquartil Calcula à mão com os quartis do ecrã:
Q3 − Q1		 Mede a largura da "caixa" (os 50% centrais dos dados).
